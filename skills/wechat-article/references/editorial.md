# 编辑与审校

用户指定的语气、篇幅和受众优先于默认偏好。标题应准确概括正文。引用应给出可见的完整 URL，或在文末列出清楚的来源。不要为了套模板而插入金句、图片、营销区块或未配置的嵌入标签。

审校事实与出处、推理跳步、重复内容、标题与正文一致性、格式，以及可能误导读者的语句。先修订，再保存定稿 Markdown；需要记录审校过程时，可在文章目录保存 `review.md`，列出问题、修订结果、仍未核实的事实和是否具备排版条件。缺少可核实资料时，只写有限结论并说明限制。

定稿后整理本篇 `article.json`。文章元数据字段为顶层的 `title`、`author`、`digest`、`content_source_url`；文件字段为 `markdown`、`html`、`cover`、`images`。摘要应与正文一致且不超过 128 字符。HTML 与 Markdown 内容应一致；链接有效；图片清晰且在正文中位置合理。清单引用路径相对于文章目录。`topic-card.md`、`research.md`、`draft.md`、`review.md` 等过程文件按创作需要保存，不要求 CLI 读取。
