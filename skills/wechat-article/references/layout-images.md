# 排版与图片

为文章单独设计版式，检查手机窄屏下的文字层级、段落间距、代码和表格表现。最终 HTML 由 Agent 根据 Markdown 定稿制作，内容应与定稿一致。具备预览能力时检查渲染效果；无法预览时仅做静态检查，并说明视觉效果未经验证。

article.json 要求提供封面图片，将其路径写入 cover。按文章内容决定是否使用正文图片，不要为了套模板插图；正文图片路径写入 images，并在 HTML 中以相对于 HTML 文件的本地路径引用。没有正文图片时，images 使用空数组。图片文件名和目录不固定。同步时 CLI 校验并上传清单中的图片，将正文图片替换为微信返回的 URL。
